Privacy Policy

Effective date: October 3, 2026

ChannelGate ("the tool") is an internal tool used only by the operator of the YouTube channel 「数字でのぞく隣の暮らし」 ("the operator") for channels the operator owns and manages. The only Google accounts that authorize the tool are the operator's own accounts. The tool uses the YouTube API Services; please also read the Google Privacy Policy.

1. Data the tool accesses

DataPurpose
The authorized channel's ID and titleTo confirm that videos are uploaded to the intended channel
The channel's own videos: metadata, status and processing detailsTo upload videos, set thumbnails and captions, fix metadata, add videos to playlists and confirm that processing and scheduled publication succeeded
The channel's own playlists (titles and IDs)To add new videos to the right playlist
Comments on the channel's own videos: comment text, like count, reply count and dateTo understand viewers' feedback and improve future videos. Commenters' names, channel IDs and profile images are not stored.
YouTube Analytics reports for the channel (views, watch time, average view duration and percentage, likes, comments, shares, subscribers gained or lost)To decide topics, video length and publishing times for future videos

The tool does not access any channel other than the operator's own, and does not collect data from people who are not the operator except the comment text described above.

2. How data is stored

  • All data is stored only on the operator's own computer, in a folder that only the operator's user account can read. It is not uploaded to any server operated by the operator.
  • OAuth tokens are stored in local files with owner-only permissions and are never shared.
  • Comment text may be processed by the AI assistant the operator uses (Anthropic's Claude) to summarize feedback. Only summaries of trends are kept in the operator's production notes; individual comments are not copied into them.

3. Sharing

The operator does not sell, rent or share data obtained through the YouTube API Services with any third party, and does not use it for advertising, except for the AI processing described in section 2.

4. Retention and deletion

  • Comment data is deleted no later than 30 days after it was retrieved (it is deleted automatically whenever comments are retrieved again).
  • YouTube Analytics data may be kept for as long as it is useful. The tool re-confirms that its authorization is still valid at least every 30 days.
  • If the authorization is revoked, all stored data obtained through the YouTube API Services is deleted within 7 days.

5. Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

6. Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: Operator of 「数字でのぞく隣の暮らし」 — hotsumi.yuki@gmail.com

プライバシーポリシー

施行日: 2026年10月3日

ChannelGate（以下「本ツール」）は、YouTube チャンネル「数字でのぞく隣の暮らし」の運営者（以下「運営者」）が、自分で所有・管理するチャンネルのためだけに使う内部用のツールです。本ツールを認可する Google アカウントは、運営者自身のアカウントだけです。本ツールは YouTube API サービスを使用しています。Google プライバシーポリシーもあわせてご覧ください。

1. 本ツールが扱うデータ

データ目的
認可したチャンネルの ID と名前意図したチャンネルにアップロードするための確認
運営者のチャンネルの動画の情報・公開設定・処理の状態アップロード、サムネイルと字幕の設定、タイトル等の修正、再生リストへの追加、処理と予約公開が成功したかの確認
運営者のチャンネルの再生リスト（名前と ID）新しい動画を正しい再生リストに入れるため
運営者の動画へのコメント（本文・高評価の数・返信の数・日時）視聴者の反応を知り、今後の動画作りに生かすため。コメントした人の名前・チャンネル ID・画像は保存しません。
チャンネルの YouTube アナリティクスのレポート（再生回数・総再生時間・平均視聴時間と割合・高評価・コメント数・共有・登録者の増減）今後の題材・長さ・公開時刻を決めるため

本ツールは運営者以外のチャンネルにはアクセスせず、上のコメント本文を除き、運営者以外の人のデータを集めません。

2. 保存の方法

  • データはすべて運営者のパソコンの中だけに、運営者のユーザーアカウントしか読めないフォルダに保存します。運営者のサーバー等には送りません。
  • OAuth のトークンは、本人しか読めない権限のファイルに保存し、他者と共有しません。
  • コメントの本文は、反応の傾向をまとめるため、運営者が使う AI アシスタント（Anthropic の Claude）で処理することがあります。制作のメモに残すのは傾向の要約だけで、個々のコメントは写しません。

3. 第三者への提供

運営者は、YouTube API サービスで取得したデータを第三者に販売・貸与・提供せず、広告にも使いません（2. の AI による処理を除く）。

4. 保存期間と削除

  • コメントのデータは、取得から30日以内に削除します（コメントを取得し直すたびに自動で削除します）。
  • YouTube アナリティクスのデータは、役に立つ間は保存することがあります。本ツールは少なくとも30日ごとに、認可がまだ有効かを確認します。
  • 認可が取り消された場合は、YouTube API サービスで取得して保存したデータをすべて7日以内に削除します。

5. アクセスの取り消し

Google のセキュリティ設定のページから、いつでもアクセスを取り消せます: https://security.google.com/settings/security/permissions

6. 変更とお問い合わせ

本ポリシーを変更する場合は、このページに新しい施行日とともに掲載します。お問い合わせ: 「数字でのぞく隣の暮らし」運営者 — hotsumi.yuki@gmail.com
